Introducción a Internet y HTML5

HTML es el lenguaje que se emplea para el desarrollo de aplicaciones web.

Está constituido de elementos que el navegador interpreta y los despliega en la pantalla.

Posee elementos para desplegar imágenes, ingresar variables, enlaces a otros sitios, listas, tablas para mostrar reportes, etc.

¿Qué es HTML5?

Para crear y visualizar una aplicación web se requiere:

  • Editor de código: Visual Studio Code.
  • Navegador de internet para probar: Edge, Chrome, Firefox, Safari, etc.

HTML utiliza etiquetas que requieren una marca de comienzo y otra de finalización. <etiqueta> </etiqueta>

Pasos para crear una aplicación web

La estructura básica de una página HTML5 es:

<!DOCTYPE HTML> 
<html>
    <head>
        <title>Hola Mundo</title>
    </head>
    <body>
        <p>Hola Mundo</p>
    </body>
</html>

¡Ahora puedes practicar editando este código!
